# Advisory Overlay Linked-Docs Review

This ledger records M61 decisions made while reviewing official links cited by
docs-derived advisory overlays. Advisory overlays remain non-official OpenAPI
metadata and should not be treated as provider truth.

## M61 Batch A

| Provider | Overlay | Decision | Notes |
|---|---|---|---|
| Action Network | `action-network-api-v2-overlay.json` | No add | The official v2 docs expose a broad OSDI/HAL API with many action types and helper links. The current overlay already captures the reviewed entry point, people, petitions, forms, events, tags, taggings, and webhooks workflow subset; broader campaign, upload, file, fundraiser, and OSDI relationship resources are deferred to a dedicated expansion to avoid an unfocused generic HAL overlay. |
| ActiveCampaign | `activecampaign-api-v3-overlay.json` | Covered | Reviewed official overview, auth, contact, list, and schema refs. The overlay already covers the focused contacts, lists, campaigns, and deals subset; linked schema/auth pages add metadata rather than additional workflow operations. |
| Acuity Scheduling | `acuity-scheduling-api-v1-overlay.json` | Covered | Reviewed official API reference and quick-start refs. The overlay already captures appointments, appointment retrieval/update/delete, availability, appointment types, calendars, and clients; linked quick-start material is auth/setup guidance. |
| Adalo | `adalo-api-overlay.json` | Covered | Reviewed official API, collections, and push-notification refs. The overlay already includes collection records and notification creation; remaining docs describe app-specific collection schemas and UI setup. |
| Adobe Acrobat Sign | `adobe-acrobat-sign-api-overlay.json` | No add | Official SDK docs point at resource-specific Swagger 1.2 JSON files and generation instructions. The overlay intentionally keeps a conservative base URI and agreement read subset; broader SDK resources should be imported from their own official JSON modules instead of hand-expanded into one advisory overlay. |
| Affinity | `affinity-v1-api-overlay.json` | Covered | Reviewed official V1 API docs and API-key support ref. The overlay already includes the main REST-shaped CRM/list, field, interaction, note, file, webhook, whoami, and rate-limit resources; linked help is credential-management guidance. |
| AfterShip | `aftership-tracking-api-overlay.json` | Covered | Reviewed Tracking API overview and tracking endpoint refs. The overlay covers the courier and tracking lookup subset used by workflow enrichment; broader tracking mutation flows remain outside the reviewed read-oriented subset. |

| Beeminder | `beeminder-api-v1-overlay.json` | Covered | Reviewed official API reference, auth-token endpoint, and app-registration refs. The overlay already covers users, goals, datapoints, charges, graph refresh, and ratchet operations; linked app registration is credential setup. |
